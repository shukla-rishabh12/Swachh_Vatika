## Tech Stack

- **Frontend:** HTML5 + CSS3 + Vanilla JavaScript
- **Backend:** Python 3.x + Flask
- **Database:** SQLite
- **AI:** Groq API (server-side only)

## Features

- Citizen waste reporting with photo + location
- Complaint tracking with full lifecycle
- Pickup request management
- Worker task assignment & management
- Proof-based task completion
- Admin verification workflow
- SwachhTokens reward system (idempotent)
- In-app notifications
- Analytics dashboard with KPIs
- Waste hotspot visualization
- AI chat assistant (Groq-powered)
- Audit logging
- Role-based access control (Citizen / Worker / Admin)
